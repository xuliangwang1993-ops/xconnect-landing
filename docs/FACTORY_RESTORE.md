|---|---|
| `AoI 视图` header button → `aoi-tree.html` (hand-port of `feat/factory-aoi-view-link` 4dcb02c; branch has no merge base) | `site/index.html` `#aoiViewLink` |

NOT merged (and why): the Node service of `factory/integrate-workbench` (`FACTORY.md`: `/`, `/workbench`, `/voice`, `/bridge/*`, `/slack/*`, `/aoi`, `/guide`, `/api/*`).
It is a different app (unrelated history; it carries the portal stage page) and cannot live in a static site. To run it as its own service:
a new Render **web service**, repo `xconnect-landing`, branch `factory/integrate-workbench`, build `npm install`, start `npm start`
(`node workbench/server-voice.mjs`), env from `workbench/.env.example`: `SESSION_SECRET`, `VOICE_TOKEN_SECRET`, `GATEWAY_BASE_URL`,
`SUPA_URL`, `SUPA_ANON_KEY`, `SUPA_EMAIL`, `SUPA_PASSWORD`, `DOUBAO_API_KEY` (+ optional `DEMO_GATEWAY_KEY`, `SUBROUTER_*`, `BOT_BRIDGE_PUBLIC_KEY_B64`, `GUIDE_MODEL_*`).
Those values were not provided, so no new service was created.
