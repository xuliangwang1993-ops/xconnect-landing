> 本导览只做讲解和带路，不会替你下单、付款或修改任何数据。内容来自仓库里的 FACTORY.md、门面页面文案、workbench/README.md 和 AoI 看板代码。每一节的 `关键词:` 用于检索，`链接:` 是可以直接打开的页面。

## 工厂总览：我搭台，你唱戏
关键词: 总览 工厂 是什么 整体 流程 怎么用 搭台 唱戏 介绍 开始
链接: 门面首页=/ ; 工作台=/workbench ; AoI 看板=/aoi
欢迎来到 X-connect 工厂！这里一共三块，像图书馆的三个阅览区：
1. **门面（搭台）`/`**：对外的委托入口。你说出想法、确认委托条件，我们提供工具、算力和生产环境。
2. **工作台（唱戏）`/workbench`**：卡片工作台。登录后可以聊天、把想法整理成卡片，再审阅、批准、执行，还能用字幕收件箱和实时语音。
3. **AoI 能力看板 `/aoi`**：只读看板，把工作台卡片或 AoI 后端的数据画成能力快照。
一般顺序是：门面上发起委托 → 工作台里整理、审阅、批准卡片 → 去 AoI 看板看能力和进度。

## 发起委托（门面）
关键词: 委托 下单 发起 新委托 立即委托 想法 需求 提交 样品
链接: 立即委托=/#commission ; 委托指南=/#help
在门面首页的「立即委托」区，用自然语言说出你想做什么，也可以点「填入三鲜手作样品单」看一个样例。提交前会做两次确认：提交内容和开工条件。导览员不会替你提交，提交要你自己点。

## 怎么写好委托：说清三件事
关键词: 怎么写 描述需求 不会写 提示词 验收 标准 使用者 场景 不可改
链接: 委托指南=/#help
不用学提示词工程，只要说清三件事：
1. **场景和不可改项**：在哪用、手头有什么原材料、哪些内容绝不能改。例如「18 道菜的 Excel，印 50 份 A4 菜单，菜名和澳元价格一个字都不能错」。
2. **使用者和价值**：谁在什么时刻看它、要做什么决定。
3. **验收标准**：要能一眼核对的硬标准，比如「手机小屏不横向滚动、价格求和完全相等」，而不是「好看、大气」。

## 进入工作台和登录
关键词: 工作台 workbench 登录 账号 key sk-xc subrouter 档位 tier 唱戏
链接: 工作台=/workbench
工作台用 `sk-xc-…` 网关 key 或 SubRouter key 登录。key 只保存在服务器端加密的 HttpOnly cookie 里，浏览器不保存。可选四档 SubRouter（3X / 2X / 1X / 0.5X）。登录后看到的卡片只属于你自己的账号。

## 卡片：整理、审阅、批准
关键词: 卡片 整理 审阅 批准 审批 card 状态 执行 任务 草稿
链接: 工作台=/workbench
工作台以卡片为中心：
- **整理**：把聊天或笔记整理成卡片。
- **审阅**：用一次独立的模型调用来检查卡片。
- **批准**：必须你亲手点，系统不会自动批准。
批准后的任务由服务器端执行器或你电脑上的 PC 执行桥（`/bridge/*`）完成。

## 聊天和模型
关键词: 聊天 对话 模型 chat model 临时对话 切换模型
链接: 工作台=/workbench
工作台的聊天走 X-connect 网关的 `/v1/chat/completions`，模型列表实时来自网关。开了「临时对话」就不会保存记录。

## 字幕收件箱和语音
关键词: 字幕 收件箱 inbox 语音 voice 豆包 麦克风 悬浮球
链接: 工作台=/workbench
字幕收件箱用一个加密 token 接收字幕文字，先存成草稿卡片，再异步整理，10 分钟内的重复内容会去重。实时语音走 `/voice`（豆包）。注意：页面里的悬浮球不能跨 App 显示，浏览器也读不到其他 App 的字幕。

## Slack 入口
关键词: slack 消息 集成 入口
链接: 工作台=/workbench
`/slack/*` 可以把 Slack 消息变成卡片，需要服务端配置 Slack 密钥后才能用。

## AoI 能力看板
关键词: aoi 看板 能力 快照 snapshot verified 验证 证据 m11 节点
链接: AoI 看板=/aoi
AoI 看板是只读的。它先连 AoI M11 后端（aoi-m11-staging-api）；连不上或没配置登录时，会退回用工作台卡片生成的 fixture 快照，并在页面上标明。规则是：只有 AoI 自己返回证据，才会显示 verified；工作台里完成的卡片最多显示 unverified。
