Redeem a code兑换码

Top-up codes add balance to your X-Connect account.

How to redeem

  1. Sign in to the X-Connect app with the account you want to credit.
  2. Open your balance / top-up screen and choose Redeem code, then enter the code.
  3. Your balance is credited to your account. [CONFIRM: single-use codes, any expiry]

Code redemption is available in the Android and desktop apps. It is not available in the iOS app. [CONFIRM: add a web redemption form here? — not built yet]

Problems

If a code is rejected, check that it was typed exactly and has not already been used. Still stuck? Contact [CONTACT EMAIL — TO CONFIRM] with the code’s first and last four characters (never the whole code in a public place).

充值码可以为你的 X-Connect 账户增加余额。

如何兑换

  1. 用你要充值的账户登录 X-Connect 应用。
  2. 打开余额/充值界面，选择兑换码，输入兑换码。
  3. 余额会记入你的账户。每个兑换码只能兑换一次。[Martin：确认兑换码是否有有效期]

兑换码功能在 Android 和桌面版应用中可用，iOS 应用中不可用。本页仅提供操作说明，不是网页兑换入口。

遇到问题

如果兑换码被拒绝，请检查是否输入完全正确、是否已被使用。仍无法解决，请联系 [联系邮箱 — 待确认]，并附上兑换码的前四位和后四位（不要在公开场合发整个兑换码）。
