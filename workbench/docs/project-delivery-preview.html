缺口（不藏）

  • 无动态定价数据源（对标 PriceLabs / Beyond）——comps 为 0 时，定价只能给情景模型。
  • 无 darktable——照片调色是 PIL/OpenCV 复刻，不是 RAW 级工艺。
  • 无 real-esrgan——1179px 截图放大到 2048 是 Lanczos，不是超分。
  • 无已验证 TTS（cosyvoice 在禁用名单）——视频只有垫乐，没有旁白。
  • 无 Lighthouse / Playwright——性能与可访问性只有静态审计，不能出真实跑分。
  • 无搜索意图→房源的公共数据入口——robots 一挡，竞品分析就断，这是结构性的。
  • 规则检索 ≠ RAG——知识包自测 100% 是规则命中，接小助手后建议换向量检索。
  • 直订站没有预订引擎——不收款、不锁房、不发确认信，只是申请表。
