      订单 · 发起人负责关单

      订单是「工厂发起 → 派到 pod → 交付 → 发起人关 pod」这一段的凭证。关单条件写在 close_policy，账单以算力供应商官方 billing 为准，我们自己只挂一个按 $/hr 估算的参考值。

      这段链怎么走

      1. 建单小助手把配方 + 一句话写成 build/private/orders.json
      2. 派单build/06_pod.py 用只读环境变量（不落盘）拉工厂算力实况，与订单对账
      3. 干活03/05 两站的重活走 ffmpeg + GPU；iSH 这边只保留 06 验收
      4. 交付成片落 runs/<id>/05_export/，QA 全过才写 delivered
      5. 关单按 close_policy 由发起人关 pod；POST /pods/{id}/stop 是只读 key 拒的那一步，界面上标成 pending，不假装已经关了
